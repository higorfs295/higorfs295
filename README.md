## 💼 Experiências & projetos anteriores

- 🐢 **Shield PCB para TurtleBot 4** — protótipo de placa custom (EasyEDA Pro) integrando sensor de gás MQ-2, RFID MFRC522, ADC ADS1115 e conversor buck para NVIDIA Jetson Orin Nano, com BOM completa e documentação de hardware.
- 🛡️ **Laboratório de cibersegurança SCADA/OT** — ambiente virtualizado com 6 VMs (OpenPLC, Kali, historiador PostgreSQL, HMI em Python), com artigo acadêmico e mapeamento normativo ISA/IEC 62443.
- 📨 **Sistemas distribuídos** — servidor TCP com protocolo baseado em frames/protobuf, evoluindo para sharding multi-nó com roteamento por SHA-256 & mensageria com RabbitMQ, Python e Docker.
- 🌐 **Site Institucional** — site institucional usando Next.js e TailwindCSS desenvolvido na Elo Júnior para empresa do setor de energia.
- 🗓️ **Painel Acadêmico** — sistema web de gerenciamento e planejamento de grade.
- 🧬 **Gêmeos Digitais** — Gêmeo Digital da EMC/UFG com eventos alimentados por IoT.
